# May Myint Myat — Personal Portfolio

A personal portfolio website showcasing my academic projects, technical skills, and educational background as a computing graduate and aspiring Software Developer and AI Engineer.

Built using **HTML, CSS, and JavaScript**, with a responsive design, light and dark themes, and interactive project screenshot galleries.

## 🌐 Live Website

**[maymyintmyat.com](https://maymyintmyat.com)**

The website is deployed on **Vercel** and connected to a custom domain.

## ✨ Features

- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Light & Dark Mode** — Switch between themes with consistent blue/teal accent colors.
- **Project Showcase** — Displays five individual academic projects with descriptions and technologies.
- **Screenshot Carousels** — Browse multiple screenshots of each project using navigation controls.
- **Smooth Navigation** — Section-based navigation with smooth scrolling.
- **Scroll Animations** — Subtle fade-in effects for a modern browsing experience.
- **Contact Links** — Direct access to email, GitHub, and LinkedIn.
- **Accessibility** — Supports reduced-motion preferences.

## 🚀 Run Locally

### Option 1: Open in a Browser

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` to view the website.

### Option 2: Run a Local Server

Open a terminal inside the project folder and run:

```bash
python3 -m http.server 5500
```

Then open:

```text
http://localhost:5500
```

### Option 3: Visual Studio Code

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## 🎨 Customization

### Update Profile Picture

Replace:

```text
assets/images/profile.jpg
```

with a new image, or update the image path in `index.html`.

### Update Website Content

Edit `index.html` to modify:

- Personal introduction
- About section
- Project descriptions
- Skills
- Education
- Contact information

### Update Styling

Edit `css/style.css` to customize colors, typography, layouts, and responsive design.

### Update JavaScript

Edit `js/script.js` to adjust interactive features such as navigation, animations, and project screenshot controls.
